# MVS-PnP：工业相机采集与三维位姿解算

基于 C++ 的机器人视觉项目，以海康机器人（Hikrobot）MVS 工业相机为图像采集基础，结合相机标定与 Perspective-n-Point（PnP）算法，探索从图像获取到目标三维位姿估计的完整流程。

## 项目简介

本项目围绕机器人视觉中的相机采集和几何位姿估计展开。

首先，对海康 MVS 相机 SDK 进行 C++ 封装，简化相机初始化、图像获取和资源管理等操作；在此基础上，结合相机内参、畸变参数以及目标在三维空间中的已知几何特征，通过 PnP 算法估计目标相对于相机的空间位置与姿态。

项目旨在将工业相机的工程化使用与计算机视觉中的几何算法结合起来，为后续的目标识别、机器人坐标系转换及视觉定位提供基础。

## 核心内容

### 1. MVS 工业相机封装

- 使用海康 MVS SDK 进行相机访问。
- 将相机相关操作封装为 C++ 类。
- 管理相机初始化、图像采集及资源释放。
- 为后续视觉算法提供图像输入。

### 2. 相机标定

- 使用相机内参描述成像几何关系。
- 使用畸变参数描述镜头成像畸变。
- 将标定参数用于后续图像几何计算与位姿估计。

### 3. PnP 三维位姿解算

PnP（Perspective-n-Point）是一类根据三维空间中的已知点与其对应的二维图像点，估计相机与目标之间相对位姿的算法。

典型输入包括：

- 目标坐标系中的三维特征点。
- 图像中的对应二维像素点。
- 相机内参矩阵。
- 相机畸变参数。

通过求解这些对应关系，可以估计目标相对于相机的旋转和平移。

### 4. 工程化与后续扩展

项目可进一步扩展至目标关键点检测、装甲板几何建模、坐标系转换以及机器人视觉定位等应用。

## 编译

在项目根目录执行：

```bash
cmake -S . -B build
cmake --build build -j4
```

如果 MVS SDK 或 OpenCV 安装在非标准路径，需要根据本地环境调整 CMake 配置。

## 运行

编译完成后，根据实际生成的可执行文件名称启动程序。

运行前请确认：

- 相机已正确连接并能够被 MVS SDK 识别。
- MVS SDK 的运行库可被系统找到。
- 相机标定参数文件路径正确。
- PnP 所需的三维模型点与二维图像点具有正确的对应关系。
